= Bereitstellungsworkflow für die Konvergenz einer vCenter Serverinstanz zur VCF Management-Domäne mit NFS-Datastores
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Einen bestehenden vSphere Cluster mit NetApp ONTAP NFS-Datenspeichern in eine VMware Cloud Foundation Management-Domäne konvergieren. Die Konfigurationsanforderungen werden überprüft, ONTAP tools bereitgestellt und NFS-Datenspeicher bereitgestellt. Mit dem VCF Installer Tool lassen sich die vorhandenen Komponenten validieren und nutzen, erforderliche neue Komponenten bereitstellen und die Plattform konfigurieren.

Dieser Workflow ist auch dann anwendbar, wenn ONTAP NFS 4.1 Datenspeicher als Hauptspeicher für die VCF Verwaltungsdomäne verwendet werden sollen.

Einen Überblick über den Konvergenzprozess bietet die VMware-Dokumentation: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Konvergieren bestehender virtueller Infrastruktur zu einer VCF"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]link:vmw-vcf-mgmt-nfs-requirements.html["Überprüfen der Konfigurationsanforderungen"]
[role="quick-margin-para"]
Die wichtigsten Anforderungen für die Konvergenz von vCenter Serverinstanzen zur VCF-Management-Domäne unter Verwendung von NFS-Datenspeichern werden dargestellt.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]link:vmw-vcf-mgmt-nfs-deploy.html["Bereitstellen von ONTAP -Tools und Bereitstellen eines NFS-Datenspeichers"]
[role="quick-margin-para"]
Stellen Sie ONTAP tools for VMware vSphere bereit und stellen Sie einen NFS-Datenspeicher bereit.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:vmw-vcf-mgmt-nfs-converge.html["Konvergieren vSphere Cluster zur VCF Management-Domäne"]
[role="quick-margin-para"]
Mit dem VCF Installer Tool können vorhandene Komponenten validiert und wiederverwendet sowie neue Komponenten bereitgestellt werden, die die VCF Management-Domäne bilden.
