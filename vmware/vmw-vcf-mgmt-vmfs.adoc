= Bereitstellungsworkflow für die Konvergenz von vCenter Serverinstanzen zur VCF-Management-Domäne mit VMFS-Datenspeichern
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Einen bestehenden vSphere Cluster mit NetApp ONTAP VMFS Datenspeichern in eine VMware Cloud Foundation Management-Domäne konvergieren. Die Konfigurationsanforderungen werden überprüft, ONTAP tools bereitgestellt und VMFS Datenspeicher provisioniert. Mit dem VCF Installer Tool lassen sich die vorhandenen Komponenten validieren und nutzen, erforderliche neue Komponenten bereitstellen und die Plattform konfigurieren.

Dieser Workflow wird auch verwendet, um beliebige unterstützte VMFS-Datastores als Principal Storage für die VCF-Management-Domäne zu nutzen.

Einen Überblick über den Konvertierungsprozess bietet die VMware-Dokumentation: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Konvergieren bestehender virtueller Infrastruktur zu einer VCF"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]link:vmw-vcf-mgmt-vmfs-requirements.html["Überprüfen der Konfigurationsanforderungen"]
[role="quick-margin-para"]
Die wichtigsten Anforderungen für die Konvergenz von vCenter Serverinstanzen zu VCF Management-Domänen unter Verwendung von VMFS-Datenspeichern werden dargestellt.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]link:vmw-vcf-mgmt-vmfs-deploy.html["ONTAP tools bereitstellen und einen unterstützten VMFS-Datenspeicher bereitstellen"]
[role="quick-margin-para"]
ONTAP tools für VMware vSphere bereitstellen und einen unterstützten VMFS-Datenspeicher bereitstellen.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:vmw-vcf-mgmt-vmfs-converge.html["Konvergieren vSphere Cluster zur VCF Management-Domäne"]
[role="quick-margin-para"]
Mit dem VCF Installer Tool lassen sich vorhandene Komponenten validieren, wiederverwenden und neue Komponenten bereitstellen, aus denen die VCF Management-Domäne besteht.
