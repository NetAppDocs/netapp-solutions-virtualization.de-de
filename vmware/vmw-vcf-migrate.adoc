= Informationen zur Konvergenz einer vSphere Umgebung mit bestehenden Datenspeichern zu einer VCF Management-Domäne
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Jede unterstützte vSphere-Umgebung kann als Teil einer VCF Private Cloud-Umgebung verwendet werden. Sie kann in eine VCF Management-Domäne konvergiert oder als Workload-Domäne importiert werden. Diese Lösung zeigt, wie bestehende VMFS- oder NFS-Datenspeicher in vSphere als primärer Speicher genutzt werden, wenn der Cluster in eine VCF Management-Domäne umgewandelt wird.



[[solution-overview]]
== Lösungsübersicht

Diese Lösung zeigt, wie bestehende VMFS- oder NFS-Datenspeicher in vSphere zu primären Speichern werden, wenn der Cluster in eine konvergente VCF-Management-Domäne überführt wird.

Dieser Prozess profitiert von der Robustheit und Flexibilität des ONTAP Speichers, wodurch ein nahtloser Datenzugriff und eine reibungslose Datenverwaltung sichergestellt werden. Nachdem eine VCF Management-Domäne durch den konvergenten Prozess eingerichtet wurde, können Administratoren zusätzliche vSphere-Umgebungen, einschließlich solcher mit VMFS- und NFS-Datenspeichern, effizient in das VCF Ökosystem importieren.

Diese Integration verbessert nicht nur die Ressourcennutzung, sondern vereinfacht auch die Verwaltung der privaten Cloud-Infrastruktur und gewährleistet einen reibungslosen Übergang mit minimaler Unterbrechung der vorhandenen Arbeitslasten.



[[architecture-overview]]
== Architekturübersicht

Die Architektur der ONTAP -Tools lässt sich nahtlos in VMware-Umgebungen integrieren und nutzt ein modulares und skalierbares Framework, das die ONTAP -Tool-Dienste, das vSphere-Plug-in und REST-APIs umfasst, um eine effiziente Speicherverwaltung, Automatisierung und Datensicherung zu ermöglichen.

ONTAP tools for VMware vSphere können entweder in HA- oder Nicht-HA-Konfigurationen installiert werden.
